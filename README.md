# 統測商管群專二老師

一個針對 **四技二專統一入學測驗－商業與管理群－專業科目（二）** 所設計的 Custom GPT 專案。

涵蓋：

- 會計學
- 經濟學

本專案透過 **Custom GPT Instructions + 官方統測資料 + Knowledge 知識庫**，建立一個以統測範圍、歷屆題型與官方資料為核心的學習輔助 GPT。

主要功能包含：

- 統測觀念教學
- 歷屆題解析
- 題目考點辨識
- 模擬題生成
- 錯題檢討
- 弱點分析
- 命題方向整理
- 考前複習

> 本專案並非模型 Fine-tuning，而是利用 Custom GPT 的 Instructions 與 Knowledge 功能建立專門用途的統測學習工具。

---

## 專案結構

```text
統測商管群專二老師/
│
├─ README.md
├─ Instructions.txt
└─ knowledge/
```

### `Instructions.txt`

Custom GPT 的主要行為規則，包含：

- 統測導向的教學方式
- 會計學與經濟學自動判斷
- 官方資料優先順序
- 解題流程
- 模擬出題規則
- 錯題與弱點分析
- 歷屆題引用規則
- 爭議題與官方最終解釋的處理方式
- 避免虛構官方資料與答案

### `knowledge/`

存放供 Custom GPT 使用的知識資料，例如：

- 當年度統測考試大綱
- 歷屆專二試題與答案
- 官方學習指引
- 官方試題研討會資料
- 官方參考樣卷
- 官方更正、釋疑與答案確認文件

# 建立方式

## 1. 建立 Custom GPT

在 ChatGPT 的 GPT 建立頁面建立新的 GPT。

建議名稱：

```text
統測商管群專二老師
```

建議說明：

```text
專門協助準備四技二專統測商業與管理群專業科目（二），
涵蓋會計學與經濟學，
依官方考綱、歷屆試題、學習指引與命題資料進行教學、解題與模擬出題。
```

---

## 2. 匯入 Instructions

開啟：

```text
Instructions.txt
```

將內容完整貼入 Custom GPT 設定中的：

```text
指令 / Instructions
```

---

## 3. 上傳 Knowledge

將 `knowledge/` 內的資料上傳至 Custom GPT 的知識庫。

建議包含：

```text
當年度考試大綱

近年正式專二試題與答案
近年官方學習指引
近年官方試題研討會

官方參考樣卷
官方參考樣卷解答
官方參考樣卷學習指引
官方更正與釋疑資料
```

---

# 建議資料優先順序

當不同來源內容發生衝突時，建議依下列順序判斷：

1. 當年度官方考試大綱
2. 官方最終釋疑、更正、答案確認或最終解釋
3. 官方歷屆試題與標準答案
4. 官方學習指引
5. 官方試題研討會
6. 其他整理資料
7. 一般會計學或經濟學知識

若一般理論與統測官方最終判定不同，考試作答應以官方標準為準。

## 歷屆題解析

可直接貼上題目文字或上傳題目圖片。

範例：

```text
幫我詳解這題，並告訴我它真正考什麼。
```

建議回答內容：

- 科目
- 章節
- 核心考點
- 解題過程
- 正確答案
- 其他選項分析
- 統測常見陷阱

---

## 模擬出題

範例：

```text
出 10 題統測程度的「需求與供給」，
簡單 3 題、中等 5 題、較難 2 題，
先不要公布答案。
```

作答後可繼續：

```text
我的答案是 ABCDABCDAB，幫我批改。
```

再要求：

```text
根據錯題再出 5 題補強題。
```

# 錯題與弱點分析

在同一段長期學習對話中，GPT 可依先前作答紀錄分析：

- 常錯章節
- 重複出錯的觀念
- 常見錯誤類型
- 後續複習優先順序

範例：

```text
根據這段對話中我做錯的題目，
整理目前會計與經濟最大的三個弱點。
```

Custom GPT 在新的獨立對話中不一定保有上一段對話的完整學習紀錄，因此長期弱點追蹤較適合固定在同一段學習對話中進行。

# 測試方式

若需要評估 GPT 是否能自行理解統測題目，而不是直接檢索官方答案，可保留一份未加入 Knowledge 的正式試卷作為盲測。

建議流程：

```text
建立 GPT
↓
加入較早年度官方資料
↓
保留一年度正式試卷
↓
禁止搜尋網路
↓
完成整份試題
↓
與官方答案比對
```

評估時除了正確率，也可觀察：

- 是否超出考綱
- 是否虛構官方說法
- 是否誤判題目條件
- 是否出現計算錯誤
- 是否混淆會計與經濟
- 是否能指出錯誤觀念

---

# 已知限制

即使加入完整官方資料，AI 仍可能出現：

- 計算錯誤
- 讀題錯誤
- PDF 擷取不完整
- 文件檢索錯誤
- 未找到最相關官方資料
- 對爭議題作出與官方最終判定不同的推論
- 模擬題品質不穩定
- 將相似題型誤判為歷屆真題

因此，AI 回答不應被視為官方答案本身。

# FAQ

## 這是 Fine-tuning 嗎？

不是。

本專案主要透過：

```text
基礎模型
+
Instructions
+
Knowledge
+
官方統測資料
```

建立特定用途的 Custom GPT。

---

## 官方資料越多越好嗎？

不一定。

比起單純增加文件數量，更重要的是：

- 資料來源可靠
- 資料年份適合
- 文件內容與統測範圍直接相關
- 官方資料優先於一般整理資料

---

## 可以加入課本或補習班講義嗎？

技術上可以，但應先確認相關著作權與使用授權。

未取得公開散布權的教材不應直接放入 Public GitHub Repository。

---

## GPT 的答案可以直接當標準答案嗎？

不建議。

尤其是：

- 爭議題
- 法規題
- 官方更正題
- 特殊會計規定
- 最新考試制度

應再次確認官方資料。

```text

↓

↓

```
